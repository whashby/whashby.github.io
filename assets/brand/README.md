# Brand badges and signature

Eight square PNG badges: 300, 500, 750, 1000, 1500, 2000, 2500 and 3000 pixels per side. The SVG master scales without loss. These extend the portfolio’s existing “wh.” identity with its blue ring and grey gradient.

The signature is intended for email:
- Open `signature/email-signature.html` in a browser, select the rendered signature, and copy it into your email client's signature editor. Review the result and send yourself a test, because email clients may alter pasted styles.
- `signature/email-signature.txt` is the plain-text fallback.
- `signature/email-signature.png` is a graphic preview. Prefer the HTML version for clickable links and selectable text.

The HTML uses standard fonts, inline styling and presentation tables, with no remote images, tracking or scripts. No unconfirmed phone number or credential titles are included.

Editable master: `badges/badge-master.svg`. Builder: `scripts/create-badges-signature.cjs`.
