# Social covers

- LinkedIn: `linkedin-cover.png`, 1584 × 396 pixels.
- Facebook: `facebook-cover.png`, 1702 × 630 pixels, a double-resolution 851 × 315 canvas.
- Editable, self-contained SVG sources accompany each PNG; they embed the site fonts.

Upload the PNG covers in each profile's cover/background photo editor. Review desktop and mobile crop previews before saving; layouts and profile-photo overlap vary by platform and device. Important text is inset, and LinkedIn's lower-left area is left free for the profile photo.

The headers use the existing portfolio identity: blue and grey gradients, charcoal text, a connected security-and-systems illustration, and the “wh.” mark. These are code-rendered brand graphics, with no portrait.

Source: `scripts/create-brand-assets.cjs`. It renders with Playwright and the local Edge browser. The dependency path is specific to the current workstation.
